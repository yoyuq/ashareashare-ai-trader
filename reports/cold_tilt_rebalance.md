# 冷落 beta 实际操作测试 — 11 窗口全 regime 再平衡 + 交易成本 vs 上证综指

生成日期: 2026-08-15 | 预注册 + 已跑 | 真实 Baostock replay parquet, 全程零模拟

## 回答的问题

用户问「那个冷落 beta 在市场上**什么情况**都有用吗」。原测试只覆盖 5 窗口 (2018熊/2019牛/2020牛转崩/
2024震荡/2025-26现期), 缺 **2015-16股灾尾部 / 2017漂亮50大盘独涨 / 2021-23** 三个 regime 段。
本测试补齐 6 个窗口到 **11 窗口**, 覆盖 2015-2026 全 regime, 回答「是否所有市场情况都有用」。

## 结论

**每月(20交易日)/每季(60日)/买入持有: 扣费后 return 与 Sharpe 均 11/11 窗口跑赢上证综指 → 可操作, 且在
2015-2026 全 regime 无条件成立。**
**每周(5日)再平衡失败 (4/11)、双周(10日)不及格 (7/11) — 冷落信号是慢变量, 高频换仓只加噪声 + 成本。**

预注册判据 (跑之前定, 禁事后调参): 扣费后月/季再平衡 return 跑赢上证 ≥9/11 (80%) → 「可操作」。
结果: 月/季/持有 **11/11 (100%)**, 超额达标。

## 关键反例窗口 (回答「无条件有用吗」的核心)

- **2017漂亮50 (小盘逆向年)**: 上证综指只 +5.46% (大盘50涨、但指数被小盘拖累), 冷落票 **20日 +8.4pp 胜、
  持有 +20.3pp**。**不是负**。原因: 策略池 = top-800 **流动性**(大市值), 底部100低换手选的是
  「大盘 + 低活跃」段 (银行/石化/电力等), 2017 大蓝筹涨、策略吃到大盘 beta, 同时避开了拖累指数的小盘。
- **2015牛转股灾 (流动性尾部)**: +47.2pp 大胜 (极端年)。疯牛期吃到小盘/全市场暴涨 + 股灾期低换手大盘抗跌。
  这是 11 窗口最大 Δreturn, 属异常值, 不代表常态。

## 机制 (诚实: 这是 beta, 不是 alpha)

跑赢上证综指的机制是**系统性 beta**, 不是选股能力:

1. **大盘 tilt**: 策略池是 top-800 流动性 (中/大市值), 基准上证综指含大量小盘。2015-2026 A股**小盘长期跑输**
   (小盘溢价为负), 故「避开小盘拖累」本身就贡献了大部分跑赢。
2. **冷落溢价**: 底部 100 低换手 (被冷落的票) 有溢价 — 低关注度 + 均值回归。
3. 两者叠加 = 「大市值 + 低换手」被动 tilt。**信息优势 N/A** (与记忆 [[cold-stock-premium]] 一致)。

## 诚实披露 (caveats)

1. **幸存者偏差**: 股票池来自当前 (2026-08-03) 快照, 2015-2026 退市股缺失。但策略池是 top-800 **流动性**
   (大市值), 大市值股极少退市, 故对策略影响有限; 然而 2015-2017 老窗口累积退市更多, 其 Δreturn (尤其 2015 的
   +47pp) 可能被轻微高估。
2. **2015 是极端异常年** (+47pp): 疯牛 + 股灾, 不具代表性。
3. **回撤不占优**: 策略最大回撤与指数相当或略差 (如 2023 -16.4% vs 指数 -14.6%), 跑赢来自收益端而非降险端。
4. **基准是上证综指** (全A市值加权): 跑赢部分来自大盘 tilt; 若对比沪深300/中证800 (大盘基准), 超额会收窄
   (未在本测试验证, 见记忆 [[cross-sectional-selection-ab]] 中「对标指数未跑赢」的历史结论)。
5. **周频失效**: 冷落是慢变量, 5日 4/11 是「别高频追逐」的硬证据。

## 怎么操作 (操作手册)

**这是被动篮子, 不是每日 LLM 选股分析。** 正确操作:

1. 每 **月** (或每季) 一次, 把可交易股票 (非ST/可交易/pe>0/pb>0, top-800 流动性) 按**换手率**排序;
2. 取**底部 100 只 (被冷落)**, **等权**各买一份;
3. 持有到下个再平衡日, 重新按换手率取 bottom-100, 换掉涨多了/换手率变高的票;
4. 全程**无个股深研、无 LLM 逐日 BUY/SELL**。

**关键边界 (不要做)**: 别每周换仓。冷落/换手率是慢变量 (一只票被冷落几个月), 每周重选只是把「当前最冷的票」
反复洗进来 — 冷落本身在均值回归, 高频追逐反而自伤 + 成本复利。5日 4/11 就是证据。

## 成本假设 (诚实披露)

- 成本按 **full-turnover 上界 31bp/次** 扣 (每期假设 100 只全换)。真实换仓率 <100% (冷落票会延续),
  实际成本更低, 故这是保守上界, 结论只会更强。
- 口径与原始 A/B 一致 (close-to-close), T+1 开盘成交的固有摩擦见记忆 [[transaction-costs-unified]]。
