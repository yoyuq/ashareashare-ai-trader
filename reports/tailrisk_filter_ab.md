# 尾险排雷过滤器 A/B — 纯规则冷落篮子 vs +排雷 (全部历史窗口)

生成日期: 2026-08-14 | 预注册 + 已跑 | 真实 Baostock replay + 基本面, 全程零模拟

## 结论

**排雷过滤器不降回撤、反而轻微削收益。冷落篮子本就干净, 「排雷」删掉的恰恰是溢价来源。**

- 核心 5 非重叠窗口: 双重排雷 **dd 不劣 5/5, 但 return 不劣仅 3/5, 跑赢指数仍 5/5**。
- 回撤变化全在 ±0.5pp 噪声内 (2018 -32.48%→-32.21%; 2019 -13.37%→-12.89%; 2020 -6.19%→**-6.55% 变差**)。
- 收益被轻微削 (2019 +38.10%→+35.74%; 2020 +32.49%→+29.42%): 删掉的低价/亏损冷票, 恰是均值回归最强的「困境反转」名。

## 为什么排雷没用 (经济机理, 非巧合)

冷落溢价 = 「被忽视而低估」。而「亏损(roeAvg≤0)/低价(<3元)」的冷票, 正因为它**看起来吓人**, 才被市场最狠地
忽视 → 低估最深 → 均值回归空间最大。所以:

- **「排雷」(删掉吓人的票) 删的是溢价来源, 不是风险。** 2019/2020 那些低价亏损冷票贡献了超额正收益。
- **回撤来源是市场 beta (2018 熊), 不是个股暴雷。** 这 5 个窗口里没有个股层面的暴雷级尾险事件,
  所以过滤器删不删, 回撤都一样 (都跟着大盘跌)。

## 对「大模型要不要做判断」的回答

- **选股**: 不需要 (beta 用规则机械拿住, 选股 alpha 六次证伪)。
- **择时**: 不需要 (低换手自带降险, 择时砍牛市)。
- **尾险排雷 (我之前提的 LLM 角色)**: **这份数据不支持** — 粗糙排雷削收益不降险; 精细排雷(连续亏损/利润暴跌/
  营收收缩) 也已证不增值 (见 `refined_tailrisk_ab_result.md`)。除非有**非公开**排雷数据源 (监管问询/舆情/关联交易),
  否则「让大模型排雷」目前没有证据能增值。

一句话: 冷落 beta 的完整答案 = **纯规则, 月频, 不叠加任何判断**。大模型在这个策略里目前没有站得住脚的位置。
