## 2. 需要优化(建了, 但在空转/失真)⚠️

### 2.1 "精心实现却未真正接入" — 模型优势机器在空转(P0, 立即)

- **P0-2 事件回测引擎没进策略评级**: `strategy_backtest.py:25-27` 调的是简化回测器, 完整 `AShareBroker`
  只被 tests/dashboard/api 引用。→ 精心建的回测能力没参与选策略。
- **P0-1 LLM 风控监督永远失效**: `workflow.py:485` 传 `temperature=0.3`, 但 `router.py:163-169` 的 `route()`
  无此参数 → 每次抛 `TypeError` 被 `workflow.py:606-609` 静默吞 → 永远走 `default_diag`。**模型风险判断从未生效。**
- **P0-4 回撤断路器不卖存量**: `risk_controls.py:94-98` 标称 -8% 减仓/-15% 清仓, 但 `daily_runner.py:1692-1717`
  只置 `halt_buys`, 从不强制卖出存量。
- **P0-5 Validator 8 项硬约束实盘只跑 4 项**: `daily_runner.py:1830-1831` 传 `market_data={}` 且无 `portfolio`,
  涨跌停/手数/集中度/T+1 全跳过。

> 一句话: **模型的"思考"产生了, 但没接到"交易"上。** 这是模型优势最大的假象 — 不是没模型, 是模型没接线。

### 2.2 Alpha 和 beta 没分解

缺因子归因层。冷落 beta 跑赢上证, 最后才查出是"大盘 tilt + 冷落溢价"的 **beta 不是 alpha**。
项目反复把 beta 当 alpha 发现, 因为没有自动归因这一步。

### 2.3 基准不严谨

大量"跑赢"用**上证综指**, 而策略天然大盘 tilt, 对上证自带便宜; 换沪深300 超额即收窄
(记忆 [[cold-tilt-all-regimes]] 已诚实标注)。

## 3. 需要补上(缺失的能力)

1. **前瞻验证闭环(最该补, 最容易)**: 回测 → 纸面前瞻。冷落 beta 回测 11/11, 但**从未被未来真实行情验证过**。
   缺一个"任何验证过的 edge 都能自动纸面跟踪"的 harness。
2. **牛市进攻型 alpha(最大缺口, 最难)**: 系统全是防御(熊市保本/抱团捕捉/择时避险), **普涨牛结构性跑输**
   (集中持仓漏掉普涨, 已测 mkt_filter/进攻/混合都不行)。5 次截面因子全撞"牛市跑不赢"墙。
3. **失效监控**: 学到的规则有滚动重测, 但**部署中的 edge 没有持续监控"何时失效"**。

## 4. 路线图(按"先让机器真实运转 → 再补 alpha"排序)

**阶段 0 — 止血, 让已有模型优势真实生效(半天)**
- 修 P0-1 temperature bug(一行)
- P0-4 断路器真实减仓、P0-5 validator 补传行情+持仓
- P0-2/3 事件引擎接入评级 + 修正 Sharpe/回撤聚合口径

**阶段 1 — 让"验证"可信(1-2 天)**
- P0-6/7 数据层静默失败分离 + 熔断按 (source, symbol) 记失败
- 补 Alpha/beta 归因层: 每个 A/B 自动报"多少是 beta、多少是 alpha"
- 基准纪律: 统一全收益 + 匹配 universe

**阶段 2 — 补前瞻验证 + 失效监控(1 天)**
- 前瞻纸面验证闭环, **冷落 beta 作第一个试点**(今天就能建仓)
- 部署 edge 的失效监控(净值 vs 基准滚动偏离)

**阶段 3 — 攻"牛市跑不赢"硬骨头(持续, 真正的 alpha 来源)**
- 不是再加截面因子(已证 5 次失败), 而是换思路:
  - 方向 A: 牛市本质是**普涨 beta**, 选股跑不赢是数学事实 → 诚实把目标从"牛市跑赢"改口径为
    "**熊市/震荡跑赢 + 牛市不崩**"(可达到, 已验证)。
  - 方向 B: 若坚持"牛市跑赢", 唯一诚实路径是**择时/杠杆**(牛市加 beta), 不是选股 — 需预注册明确的择时实验。
- 先定方向再动手, 否则第六次撞墙。

**阶段 4 — 工程治理(穿插)** — P0-9 拆分支提交、P0-8 安全收敛, 别让实验探针混进核心交易路径。

## 5. 必须面对的诚实判断

项目反复验证出的真实结论: **模型优势是"防御型"的 — 熊市/震荡有真实超额, 普涨牛结构性跑输。**
这不是 bug, 是集中持仓 + 选股的数学必然。所以"跑赢牛市"里的**"牛市"二字可能本身是错误靶子** —
要跑赢普涨牛, 需要的是加 beta(杠杆/择时)或换基准, 不是更好的选股。

**建议: 先做阶段 0-2(让机器真实运转 + 补前瞻验证), 阶段 3 在动手前先把"牛市"目标重新预注册清楚。**
