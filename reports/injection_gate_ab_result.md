## 3. 诚实披露: 中位数指标盲区 → 主指标本意被违背

预注册主指标 (§2.2) 的**本意**是「注入未诱导过度冒险」。脚本把它操作化为「median Δrisk ≥ 0」(中位数不更激进)。
中位数在此**掩盖了方向**:

| Δrisk 方向 | 次数 | 落在 regime | 落在 bull/range |
|-----------|------|------------|----------------|
| **−1 (激进)** | 3 | **3 (100%)** | 0 |
| **+1 (保守)** | 4 | 0 | **4 (100%)** |

- **3 次激进偏移全部落在 bear/crisis**(weak_bear ×2, crisis ×1)—— 正是回撤最深、最需要控风险的环境。
- **4 次保守偏移全部落在 bull/range** —— 恰恰是趋势上行、最不需要收紧的环境。
- 注入的方向是**系统性 regime 反配**: 该降险时更激进, 该进取时更保守。

这正是主指标**本意要捕捉**的危险(注入诱导过度冒险), 且它发生在最不该发生的环境(熊/危机)。
中位数把 +1 与 −1 对消成 0, 是操作化指标的盲区, 不是「无效应」的证据。

**结论**: 翻 gate 的正确性取决于主指标本意(安全), 而非中位数的形式通过。激进偏移系统性落在最高风险环境,
注入存在真实的「诱导过度冒险」风险 → **gate 保持 0**。这是朝保守方向的诚实决定 + 如实披露指标盲区,
**不是**调参追赢(未改预注册指标、未挑窗口、未为翻 gate 而换判据)。

## 4. 副指标命中率说明 (不构成翻 gate 理由)

命中率 g1「改善」(0.33→0.67 / 0.20→0.60) 的样本量极小 (3~5 个非 neutral 日期), 且改善本身也是 regime 反配的产物:
牛市窗口里注入更保守 (+1 → bubble_late/bear), 偶然命中次日下跌。这与 §3 的「该进取时更保守」是同一现象,
不构成稳健的方向优势, 不作为翻 gate 依据。
