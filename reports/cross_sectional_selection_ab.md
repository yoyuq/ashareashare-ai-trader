# 截面选股 A/B — 低估质量选股能否跑赢等权市场 (方案3c)

生成日期: 2026-08-13 | 状态: **预注册 (跑 A/B 前锁定, 禁止事后调参追赢)**

## 待检验假设

用户假设: "牛市里, 上涨的票和下跌的票并存 (dispersion), 只要能更好地分析市场局势、对优质股票交易, 就能跑赢市场 (买入持有)。"

本项目此前"牛市跑不赢"结论只针对**择时规则** (趋势逃顶/移动止损/金字塔等); **截面选股** (从广 universe 里挑优质票) 是独立的、欠测的杠杆。本 A/B 检验选股这条路径。

## 数据约束 (如实声明)

`replay_data/*.parquet` 基本面字段仅有 `peTTM / pbMRQ / turn(换手) / amount(成交额) / isST / is_trade`,
**无 ROE / 营收增速 / 市值**。因此"优质股"只能用 **低估值 (低 PE × 低 PB)** 忠实代理 — 这正是系统
自主学习闭环里唯一验证通过的规则 `low_pe_value` (低估值价值), 参数用 tester 忠实默认
`max_pe=15.0 / max_pb=2.0`。这使本 A/B 直接检验"系统自己学到的规则, 作为选股, 能否跑赢市场"。

## 预注册设计

### 窗口 (3)

| 窗口 | regime | 数据文件 |

| 2020牛 | 牛 (2020-06→2021-02) | `daily_2020-06-01_2021-02-28.parquet` |
| 2024震荡 | 震荡 (对照, 非牛) | `daily_2024-01-01_2024-12-31.parquet` |

### Universe (每窗口, 首日截面)

可投资 = `isST=='0'` 且 `is_trade==1` 且 `peTTM>0` 且 `pbMRQ>0`, 剔除指数符号 `sh.000001`。
覆盖 ~2900~3800 只 (见下方前置 sanity check)。

### 基线

- **B1 (主基准)**: 等权买入持有**全部 investable universe** (= 等权市场组合)。
- **B2 (参考, 仅 2020 有数据)**: 上证指数 `sh.000001` (市值加权大盘指数, 2020 窗口 +21.9%)。

### 处理组 (两条预注册, 均忠实映射系统 learned low_pe_value)

- **T1 阈值**: `peTTM < 15.0 且 pbMRQ < 2.0` 的票, 等权买入持有 (忠实 `low_pe_value` 买入谓词)。
  每窗口选 359~537 只 (12~18% of investable)。
- **T2 排序**: 按 `peTTM` 升序取 top-30 (纯低估值极值), 等权买入持有。

### 指标 (等权组合日频路径)

窗口总收益 `return%`, 最大回撤 `maxDD%`, 年化夏普 `sharpe`。买入持有向量化:
每票 `ret = 末收盘/首收盘 - 1`, 等权平均; 日频净值 = 各票归一化收盘的均值 (前向填充), 用于 dd/sharpe。
基线/处理组**同构** (均无换手、无费率、单期持有), 故差分隔离**纯选股效应**。

### 判据 (预注册, 禁止事后调参)

- 主判定: 处理组 return > B1 的窗口数 **≥ 2/3** → 选股 alpha 成立; 1/3 → inconclusive; 0/3 → rejected。
- T1、T2 各自独立判定, 不合并挑优。
- 2024震荡作为**对照** (非牛): 如实报告选股效应在非牛是否也成立, 不改变主判定。

## 诚实局限 (预注册时即声明)

1. "优质" = 低估值代理 (无 ROE/质量/成长因子)。
2. 等权非市值加权 (缺市值字段; 等权偏向小盘, 在 2019-2020 小盘强势下, B1 可能显著高于上证指数 → "跑赢等权市场" 比 "跑赢指数" 更苛刻)。
3. 单期 buy-and-hold, 无再平衡 (隔离纯选股, 再平衡留作后续)。
4. 退市/停牌票以其窗口内最后有效收盘计收益 (可能低估其损失)。
5. 指数仅 2020 有数据, 2019/2024 以等权市场 (B1) 为唯一基准。

**预注册判据 (return > B1 的窗口数 ≥ 2/3)**:
- T1 (pe<15&pb<2): **2/3 跑赢 → 选股 alpha 成立** (2020 +7.86pp, 2024 +13.57pp; 2019 -7.55pp)。
- T2 (top30 极低 PE): 1/3 跑赢 → inconclusive (仅 2024 +32.70pp; 两牛皆输)。

## 诚实解读 (比判据数字更重要)

1. **2019 牛 (真牛市) 里低估选股跑输等权市场 -7.55pp** —— 用户假设"牛市选优质股跑赢"在一个真牛市里
   **不成立**。2019 是成长/科技驱动的牛市, 便宜股(低 PE/PB)是"价值陷阱"(旧经济/传统行业), 跑输含全部
   成长票的等权市场。
2. **2020 牛里 T1 虽跑赢等权 +7.86pp, 但跑输上证指数**(+15.54% vs 指数 +20.36%)。等权市场
   (小盘重) 2020 下半年被核心资产行情碾压 (+7.68% vs 指数 +20.36%), 故"跑赢等权" ≠ "跑赢市场(指数)"。
3. **真正的大赢在 2024 震荡**(T1 +13.57pp, T2 +32.70pp) —— 这是"红利/价值"风格年 (银行/煤炭/中字头
   估值重估), 是**价值回归/降险**, 不是牛市 alpha。
4. 对标市值加权指数方向看, 低估选股**三个窗口均未明确跑赢**(2020 已实证跑输; 2019/2024 指数数据
   replay_data 未含, 待精确复验)。

**结论**: 用户假设"牛市里选优质股(低估值代理)跑赢市场"**未被证实**。系统唯一稳健的 learned 规则
(low_pe_value) 的价值仍落在**非牛/震荡市的降险与价值回归**, 而非牛市选股 alpha —— 与进化、知识注入
两次 A/B 撞同一堵墙。要测"优质成长股跑赢牛市", 需 ROE/营收增速/市值字段, 当前数据不具备。
