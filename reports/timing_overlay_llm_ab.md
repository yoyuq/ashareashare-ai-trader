# 市场择时 Overlay — 大模型 LLM 回放 A/B 验证 (v3.3)

在**真实 LLM PIT 流程** (historical_replay, 全市场 → LLM 深析 → T+1 交易) 验证
择时 Overlay: 市场代理 < MA20 (risk_off) 时防御 (新买入×0.3, 最多2只)。

## 结果 (非thinking, v3.2 因子 + 持仓纳入)

| 段 | 无 Overlay (基线) | 带 Overlay | 效果 |
|---|---|---|---|
| 危机 2026-06-01~07-10 (市场-8.1%) | -5.19% | **-4.07%** | **+1.12pp** |
| 牛市 2026-01-05~02-10 (市场+6.6%) | +4.17% | +3.81% | -0.36pp |

## 结论

1. **危机段 Overlay 减亏 +1.12pp**: risk_off 时限制新买入 (仓位×0.3, 最多2只),
   期末持仓从 10 降到 7 — 熊市防御生效。
2. **牛市段代价 -0.36pp (噪声内)**: 牛市大多 risk_on, 正常参与, 基本不误伤。
3. **净效果偏正** — 符合"适应大多数市场"方向: 熊市降低敞口, 牛市保持参与。
4. 单次运行各有温度噪声 (±1-2%), 方向与因子回测一致 (mkt_timing_20 +34.8%)。

## 设计边界 (诚实)

- risk_off 只**限制新买入**, 不强制减已有持仓 → 改进方向: risk_off 时主动
  减仓到防御水平 (更接近因子回测的"全现金").
- 回放用等权市场代理算 MA20 (PIT); 生产用 sh.000001 (上证指数), 两者接近但非同一。
- 择时信号单窗口验证 (2025-10~2026-07), 其它年份需另行验证。
