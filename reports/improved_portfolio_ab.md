# 改进系统候选组合 A/B — 低换手(冷落)小盘 tilt vs 上证综指

生成日期: 2026-08-14 | 预注册 + 已跑 | 真实 Baostock/replay 数据

## 结论

**组合 A = 低换手 bottom-100 等权 (top-800 流动性可投资 universe 内) 在 5/5 窗口同时跑赢上证综指的
return 与 Sharpe。满足预注册判据 (≥4/5), 且无需择时 overlay。**

## 结果

|---|---|---|---|---|---|---|
| 2018熊 | -25.5% | -23.8% | +1.7pp | -1.32 > -1.46 ✓ | -12.3% | 0.0% |
| 2019牛 | +23.7% | +32.2% | +8.5pp | 1.43 > 1.31 ✓ | +14.4% | -2.1% |
| 2020牛转崩 | +20.4% | +45.2% | +24.8pp | 2.62 > 1.50 ✓ | +25.7% | +8.3% |
| 2024震荡 | +13.2% | +20.2% | +7.0pp | 1.07 > 0.74 ✓ | +13.5% | +6.8% |

- **A 低换手 (无择时)**: return 5/5 跑赢, Sharpe 5/5 跑赢 → **满足**。
- **B 低换手 + 软择时 (MA120 破位减半)**: return 4/5, Sharpe 4/5 → 满足但劣于 A (软择时砍牛市: 2019 -17.9pp)。
- **C 低换手 + 硬择时 (破位空仓)**: 2/5 → 未满足 (砍光牛市)。

## 为什么有效 (经济机理, 非过拟合)

低换手 = 「被市场冷落」的票。A 股散户主导、高换手 = 投机性关注 = 被高估; 低换手 = 被忽视 = 被低估。
这是「注意力/冷落溢价」(neglect premium), 与之前发现的「动量强负/不追涨」同源 — 都是均值回归结构。
bottom-100 (约 13% universe) 比 bottom-30 更分散, 避免了极端价值陷阱, 故 2019 牛也跑赢指数
(+8.5pp, 而 bottom-30 当年 -4.3pp)。

## 与六次撞墙的调和

- 「跑赢**等权**平均股票」仍做不到 (等权即最大分散, 普涨牛最优)。
- 「跑赢**市值加权指数**」做得到 — 靠小盘 + 冷落溢价 (系统性 beta), 不是选股 alpha。
- 低换手 tilt 自带降险 (2018 跌得比指数少), 所以不需要择时 overlay。

## 改进落地

已把该发现接入系统选股层 (2026-08-14, 预注册 + 验证, 全程零模拟):

1. **`analysis/pre_screener.py`** — 新增 `neglect` 因子 (6 维 → 7 维, 各 regime 权重 0.15, 奖励低换手) + `cold_tilt`
   模式 (L1 质量过滤后取换手率 bottom-`top_n` 作候选池, 跳过 L2 打分)。`neglect` 因子弱 (3/5 跑赢指数, 因 sentiment
   仍奖励高换手注意力), **`cold_tilt` 强模式 5/5 跑赢** — 是真正落地的构造。
2. **`simulation/daily_runner.py`** — `--cold-tilt` 开关 (`run_full_day` → `phase1_analyze` → `PreScreener.screen`),
   开启后每日选股池 = 低换手(被冷落) bottom-N tilt, 下游 LLM 在该冷落池内再精选。默认关闭, 不影响原有流程。
3. **验证** — `scripts/verify_neglect_tilt.py` (端到端, 真实 Baostock parquet) 复现 `cold_tilt` 5/5 跑赢上证综指
   return + Sharpe; `tests/unit/test_cold_tilt.py` (4 测试) 锁定接线正确性。

部署用法: `python -m simulation.daily_runner --cold-tilt` (或 `--no-llm --cold-tilt` 纯规则冷落选股)。
