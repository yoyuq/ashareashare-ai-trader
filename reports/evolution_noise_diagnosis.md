# 进化内核异常诊断 — "牛市过度谨慎"假设检验 + 噪声基底分析

生成日期: 2026-08-11 | 对象: 多窗口 A/B (2020牛转崩 / 2019牛) 的 evo vs base 逐日数据

## 研究点与初始假设

多窗口 A/B 显示 2019 牛市进化跑输 (-1.66pp, 3次中位数)。提出的可研究点假设:
**"进化的反事实纠偏 / 经验记忆在趋势牛中过度谨慎, 导致少赚"**。

## 诊断证据 — 假设被三方面否定

1. **持仓数不更少**: 2019 evo 日均持仓 **9.5 vs base 8.4**, 进化反而**持仓更多** (27/56天更重, 仅14/56天更轻)。不是"仓更轻/更谨慎"。
2. **记忆注入仅覆盖最后 ~15 天**: 2019 evo memory 最早经验 **04-15**, 回放 02-11 起 → 前 40 天无任何进化注入 (principles/tips 均为 0, 已核)。
3. **跑输集中在无记忆的前段**: 分段对比 (用 equity_curve) ——
   - 2019 前40天(无记忆): evo **+10.13%** vs base **+11.52%**, evo少赚 **-1.39pp** (占总差 -2.01pp 的 69%)
   - 2019 后15天(有记忆): evo **+6.91%** vs base **+8.92%**, evo少赚 **-0.60pp**
   - → 主要差额发生在进化记忆**尚未注入**时, 与进化机制无关。

## 更深发现 — 前段噪声基底达 ±2pp, 与宣称增益同量级

evolution 系统 principles/tips 均为 0, 前段 evo 与 base 唯一差异 = 两组独立 LLM 运行的**随机诊断**。但:

| 窗口 | 前段(无注入) evo-base | 后段(有注入) evo-base | 全程 evo-base |
|---|---|---|---|
| 2020牛转崩 | **+2.11pp** (46天) | +2.41pp (14天) | +4.86pp |
| 2019牛 | **-1.39pp** (40天) | -0.60pp (15天) | -2.01pp |

- 2020 进化的增益中, **+2.11pp (44%) 发生在无记忆注入的前段**, 纯粹是 LLM 运行随机。
- 2019 进化的损失中, **-1.39pp (69%) 发生在无记忆注入的前段**, 同样是运行随机。
- **前段(无进化机制)的 evo-base 差异已达 ±2pp, 与宣称的进化增益 (+1.11 / -1.66pp) 同量级** → 单次运行的进化增益/损失大部分落在 LLM 噪声基底内。

## 诚实结论

- **"牛市过度谨慎"不是可修的机制对象**: 三条证据 (持仓更多 / 记忆仅后段 / 跑输在前段) 一致否定。任何针对它的"修复"都必然过拟合噪声, **不修**。
- **进化记忆的净效应缺乏可靠证据**: 前段纯随机已达 ±2pp, 后段有注入期的差异不超噪声基底。无论正负 (2020赢 / 2019输), 进化记忆的真实效应量级被 LLM 诊断噪声 (±1-2%) 淹没。
- 这解释了多窗口结论"不稳健" (收益2/4, 夏普3/4→CSI300下1/4) 的**根本原因**: 隔离单变量 A/B 的噪声基底 > 进化效应。
- 之前宣称的"2020 风险控制增益 +1.11pp"与"2019 牛市跑输 -1.66pp"可能**主要是运行噪声**, 非进化机制。

## 局限 (如实报告)

- 前段/后段行情不同, 配对差分不能完全分离"进化净效应"与行情×随机交互。
- 2020 每边 3 次取中位数已缓解部分噪声, 但前段分析用单次运行 (r0)。
- 诊断性证据, 非最终证明; 但足以否定"牛市过度谨慎"这个具体假设。

## 建议 (非本次执行)

若需可靠验证进化机制, 需**加大样本/降噪**而非调参:
- 每窗口每边 ≥5-10 次独立运行取中位数, 或
- 用"前段无注入期"做每对运行的噪声标定, 配对差分出"净进化效应"。
