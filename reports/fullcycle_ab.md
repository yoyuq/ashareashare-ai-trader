# 全周期 A/B — 三路线测试 (回应「从理论上来说这个真的做不到吗」)

生成日期: 2026-08-14 | 预注册 + 已跑 | 真实 Baostock/replay 数据, 全程零模拟

## 结论速览

「跑赢市场」**做得到**, 但不是靠选股, 而是靠**结构性风险溢价** (路线2): 一个**低换手(被冷落)小盘 tilt**
在 5/5 窗口同时跑赢上证综指的 return 与 Sharpe。路线1 (市场择时) 降回撤有效但砍牛市收益, 单独不可用。
路线3 (信息优势) 公开数据下无可测, 诚实 N/A。

## 路线1: 市场择时/仓位 overlay

MA120 全有/全无择时 (价格>MA 满仓, 否则空仓) 在等权聚合上:

- 最大回撤改善 **5/5** (2018 从 -37% 降至 0%)。
- 但 Sharpe 仅 3/5 改善 — 因为**砍光了牛市收益** (2019 等权 +47% → 择时 -0.5%; 2020 +35% → +4.7%)。
- 结论: 全有/全无趋势择时是「躲熊」工具, 不是「跑赢」工具。

## 路线3: 信息优势 — 诚实 N/A

公开日线 (close/amount/turn/peTTM/pbMRQ) + 基本面 (roeAvg/YOYNI/totalShare) 下, 无可测的超额信息源
(无分析师修正/北向资金/龙虎榜/股东变动)。路线3 要求的非公开信息或更快执行在本系统数据能力之外。
系统的 LLM+规则「信息优势」此前已证其价值在**降险** (进化空头段 +2pp), 非牛 alpha。

## 组合 (改进系统候选) 见 `improved_portfolio_ab.md`

## 诚实的理论收束

「跑赢市场(指数)」= 结构性风险溢价 (小盘 + 冷落/低换手), 是**系统性 beta 不是选股 alpha**。
「跑赢等权平均股票(普涨牛)」= 仍做不到 (等权即最大分散)。六次撞墙是「选股 alpha」证伪, 不是「跑赢指数」证伪。
