## 2. 诚实总评

### 2.1 实证上确实有利的
- **估值维度此前是真实盲区**: indicators.py 130+ 指标零估值, AI 技术分析从没见过
  PE/PB 相对历史分位。补上 ep/bp/pe_pct_20d 是事实性改进。
- **40 天实测的估值暴露变化是确定性的** (非噪声): 买入中位 PB 2.12→1.55,
  EP 0.47→0.64。这是 prompt 直接加估值因子的必然后果。
- **三个独立窗口、两种 universe 因子回测方向一致**: 估值最强或次强。
- **当前均值回归/熊市窗口内, 改动让交易"少亏 + 更抗跌"**: 收益 +0.61pp,
  回撤小 23%。

### 2.2 实证上没帮助、该砍掉的
- **regime 动态切换因子集是失败设计**:
  - 长窗口 (830 SH, 199d): regime_adaptive -8.8% **输给纯估值 value -6.9%**;
  - 全市场 110d: -14.0% vs value -3.7%。
  - 结论: **不是因子越多越聪明, 简洁的估值核心更稳。** 该复杂度是负债不是资产。

### 2.3 关键: 改动尚未进入自动交易主循环
- 提交的 technical_analyst / workflow 改动走 **AnalysisWorkflow (单股深度分析/dashboard)** 路径。
- **daily_runner (每日自动交易主循环) 不走该路径**, 它用自己的
  `_flash_screen` / `_deepseek_analyze` (本就带 PE/PB + PreScreener 估值维度)。
- 因此**这些改动对自动交易的实际影响当前为 0**; 40 天 A/B 的 v32 prompt
  (historical_replay `--variant v32`) 是测试钩子, 不是生产默认。

### 2.4 最该警惕的: 全部证据来自同一窗口
因子研究 / regime 分析 / 40 天 A/B 均落在 2026-02~07 的均值回归/熊市段。
**牛市里动量翻正、价值可能滞涨** (830 只样本 IC 已显示 momentum_20 牛熊翻转)。
当前的价值倾斜是"按当前窗口下注", 市场转牛可能反噬。牛市窗口未做持仓回测验证。

## 4. 结论

**"对当前有利"勉强成立**: 估值注入在均值回归市确实少亏、更抗跌、选股更便宜,
且方向与多窗口因子研究一致。

**"对未来有利"证据不足**: 提升幅度在单次 LLM 噪声范围内 (+0.61pp),
全部证据绑定当前熊市窗口, 且改动尚未进入 daily_runner 自动交易主循环。
regime 动态切换已被实测证伪, 应弃用。

## 5. 牛市段验证 (v3.2 补证据) — 价值倾斜的 regime 风险被实证确认

用 830 只 SH 长回放截取**牛市段** (2025-11~2026-02, 市场等权 +8.7%)
做同款因子选股回测 (见 reports/factor_backtest_bull.md):

| 策略 | 总收益 | 最大回撤 |
|---|---|---|
| baseline | -8.8% | 17.9% |
| value (ep+bp) | **-4.6%** | 6.6% |
| rec | -4.8% | 10.1% |
| **market (等权)** | **+8.7%** | 5.4% |

**核心发现:**
- **牛市段所有因子 top-K 策略都跑输市场** (value 落后 13pp, baseline 落后 17.5pp)。
  这不是"价值滞涨", 而是**因子 top-K 整体没抓住这段 +9% 行情**。
- 与熊市段对照 (value -3.7% vs 市场 -14.9%, 跑赢 11pp):
  **价值 = 熊市保险, 牛市里会落后**。教科书式防御性特征, 现在有了同一框架下的
  双向实证。
- **对 v3.2 价值倾斜的直接含义**: 当前熊市窗口倾斜合适; 若市场转牛, 必须靠
  regime 门控降低价值权重、恢复动量/趋势优先 (已接入 daily_runner 主循环的操作原则
  "牛市: 动量/趋势信号可信, 强势优先, 估值次之")。
