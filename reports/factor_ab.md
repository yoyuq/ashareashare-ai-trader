# 横截面因子 A/B (方案3e) — 低换手/反转/动量/低波 能否跑赢等权市场

生成日期: 2026-08-14 | 状态: 预注册 + 已跑

## 背景

撞四次墙 (价值/成长/择时/进化 均非牛市alpha) 后, 学习闭环联网研究 (Bocha 真搜索) 了
动量/反转/低换手/低波/股息 五类异常, 但规则测试器无法忠实表达"按因子排序选top-N", 全部
`not_yet_testable`。本 A/B 直接测这四个交易类因子 (脚本 `scripts/run_factor_ab.py`)。

## 数据与方法

- lookback: 因子需窗口起点 T 之前的历史收益/换手, 补抓了 2020 (2020-03~06) 与 2024
  (2023-11~2024-01) 两段 Baostock 日线 (`scripts/fetch_factor_lookback.py`); 2019 用已有
  `daily_2018-10-01_2019-12-31.parquet`。
- 因子 (point-in-time, 在窗口起点 T 处计算, 各 top/bottom-30):
  - **low_turn 低换手** = turn(T) 升序 bottom-30 (被市场冷落的票)
  - **reversal 反转** = 过去20日收益 升序 bottom-30 (买超跌)
  - **momentum 动量** = 过去20日收益 降序 top-30 (买强势)
  - **low_vol 低波** = 过去40日日收益std 升序 bottom-30
- 基线 B1 = top-800 流动性可投资 universe ∩ 窗口首日可交易 (剔除次新幸存者偏差)。
- 判据 (预注册): return > B1 的窗口数 ≥ 2/3; 每因子独立判定, 不合并挑优。

## 诚实结论 (第五次撞墙 + 一个新发现)

1. **六类因子 (价值/成长/反转/动量/低换手/低波) 在 2019 真牛市全部跑输等权市场**。普涨牛市里
   "广撒网等权"本身即最强组合, 任何选股因子的集中度都是负的超额。
2. **动量在 A 股是强负 alpha** (两窗口 −30pp): 追涨 (买近期强势票) 稳定跑输。A 股是均值回归市场,
   这是本轮唯一稳健、可复现、可执行的新结论 —— **"不追涨" 作为负向规则成立**。
   (注: 学习闭环研究员联网蒸馏出"A股短期动量强"是**错的**, 直接回测为准: 20日动量强负。)
3. **低换手 2/3 判据"成立", 但赢在非牛** (2020 +3.7 / 2024 +13.0), 2019 牛 −27.5pp —— 与
   低估值/成长同一模式: 被冷落的小票/价值票在非牛结构性行情里补涨, 非牛市 beta。
4. 反转/低波均不稳健 (反转 2020 +10.5 但 2024 −18.2; 低波牛负震荡正)。

## 方向

停止追求"跑赢牛市"。系统被五路 A/B 反复印证的真实价值 = **非牛/震荡市的降险与结构回归**
(进化空头段降险、低估值价值回归、低换手补涨), 而非牛市 beta。下一步应把这些已验证的降险能力
组合成防御型组合, 目标是**风险调整后超额 (高 Sharpe / 低回撤)** 而非跑赢普涨牛。
