## 说明

本比赛指定使用**蓝鹰敏学智能体开发平台**(北京中云国创)。我们的项目基于自研技术栈(Python/LangGraph/Streamlit),本文档详细说明自研系统的每个模块如何1:1对标蓝鹰敏学平台的核心能力。

如果评委询问"你们没有用蓝鹰平台吗?",本文档提供完整的回答框架:
- 我们的系统实现了平台要求的所有核心能力
- 每个模块都可以直接在蓝鹰平台上重新实现
- 自研技术栈的选择体现了更深层的工程理解

## 评委可能问的问题及回答

### Q1: "你们为什么不用蓝鹰敏学平台?"

**回答框架**:
"蓝鹰敏学是一个优秀的低代码AI智能体开发平台。我们的项目从架构设计上完全对标了平台的5大核心模块(数据搭建/知识库/提示词/工作流/测试)。选择自研技术栈的原因是:
1. **更深层的技术理解**: 平台拖拽操作背后是LangGraph/MCP/Function Calling等底层机制,自研意味着我们掌握了这些底层原理
2. **更强的定制能力**: 比如130+技术指标计算、T+1真实A股约束回测、8层风控,这些金融领域的深度需求超出了通用平台的能力边界
3. **可迁移性**: 我们的知识库(YAML/MD/提示词)可以直接导入蓝鹰平台,工作流逻辑可以1:1迁移

如果比赛要求平台操作,我们可以在1-2周内将核心功能迁移到蓝鹰平台。"

### Q2: "你们的知识库是怎么搭建的?"

**回答框架**:
"我们构建了三层知识体系:
1. **结构化规则层(YAML)**: A股交易规则、技术指标手册、策略注册表 — 可以直接被Agent读取和验证
2. **参考文档层(Markdown)**: 术语表(45个术语)、市场周期(7轮牛熊)、基本面估值阈值 — 支持RAG检索
3. **向量检索层(ChromaDB)**: K线形态相似度检索 — 在分析流水线中真正使用,不只是展示

知识库的每一层都可以独立更新,修改后即时生效(热更新),不需要重启系统。提示词通过`{placeholder}`自动注入知识库内容。"

### Q3: "你们的提示词是怎么优化的?"

**回答框架**:
"我们建立了一套系统化的提示词工程体系:
1. **版本管理**: 每个提示词文件包含YAML frontmatter(version/date/author/changes)
2. **A/B对比**: 我们做了v1.0→v1.1的迭代优化,通过PromptEvaluator的4维评估,总分从24.5提升到32.0(+30.6%)
3. **评估框架**: 使用LLM-as-Judge进行4维度评分(格式合规/数值准确性/逻辑一致性/风险提示)
4. **Few-shot**: 4组场景化few-shot样例,覆盖恐慌抛售/板块轮动/止损执行/信号复核

你可以看到`docs/competition/PROMPT_AB_COMPARISON.md`中的详细对比报告。"

### Q4: "你们的创新点在哪里?"

**回答框架**:
"三个核心创新:
1. **对抗辩论机制(Bull/Bear/Judge+Critic)**: 行业首创的正反方+裁判+审计四层验证。Bull和Bear基于同一份量化数据辩论,Judge结构化裁决,Critic独立审计方法论缺陷。这比单一Agent的'分析'更客观。

2. **代码即推理(Code-as-Reasoning)**: 从根本上杜绝LLM数值幻觉。LLM生成计算代码→沙箱执行→数字锁定→LLM叙事→NumericSafetyChecker校验。

3. **资本-资产匹配评估**: 基于2026年WAIC发布的评估新框架。我们不只看'回答是否像人类分析师',更看'智能体能否将用户风险偏好与产品特征进行合理匹配'。'主动拒绝'和'信息不足'都是有效回答——这比盲目给出建议更负责任。"

## 如果在蓝鹰平台上重新实现

如果需要,以下是自研系统→蓝鹰平台的迁移方案:

| 自研组件 | 蓝鹰平台对应功能 | 迁移工作量 |
|---------|----------------|----------|
| YAML规则文件 | 知识库 → 文档上传 | 直接导入 (1小时) |
| 提示词文件(.txt) | 提示词工程 → 提示词管理 | 复制粘贴 (2小时) |
| 7节点工作流 | 工作流 → 节点拖拽编排 | 逐个配置 (4小时) |
| 130+指标计算 | Python代码节点 | 嵌入代码块 (2小时) |
| ChromaDB RAG | 知识库 → 向量检索 | 需要确认平台是否支持 |
| Dashboard | 平台自带展示 | 无需迁移 |
| PPT答辩 | PPT导出功能 | 直接使用平台模板 |

**总预估**: 核心功能迁移约1-2个工作日。
