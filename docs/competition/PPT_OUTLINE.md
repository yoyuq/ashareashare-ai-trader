### 第一部分: 智能体设计思路与构架 (10分, ~5页)

**P1. 行业痛点与需求分析**
- A股5000+股票,投资者信息过载严重
- 传统分析依赖人工,效率低、易受情绪影响
- 需要一个系统化的AI量化分析助手

**P2. 智能体设计理念**
- Multi-Agent协作: 7个专业子Agent分工协作
- 量化数据驱动: 所有数字由代码计算,LLM只负责叙事
- 对抗辩论机制: Bull/Bear/Judge三方辩论,防止单一视角偏差
- 3层成本优化: 本地免费→低价API→深度推理的智能路由

**P3. 系统架构图**
- 使用 Mermaid 生成的整体架构图
- 展示: 用户入口 → Agent协作 → 模型路由 → 知识库检索

**P4. 工作流拓扑**
- 7节点 LangGraph 分析流水线
- 节点详情: 输入/输出/模型/耗时

**P5. 技术创新点**
- 代码即推理 (Code-as-Reasoning): LLM生成代码→执行→锁定数字→叙事校验
- 对抗辩论: Bull/Bear基于同一份数据辩论,Judge结构化裁决
- 多源数据融合: 4个数据源自动fallback+交叉验证

### 第二部分: 智能体开发制作过程 (40分, ~8页)

**P6. 技术栈总览**
| 层级 | 技术 |
|------|------|
| LLM | DeepSeek V4 + Ollama Qwen3 |
| Agent框架 | LangGraph + Function Calling |
| 数据 | AKShare/Baostock/EastMoney/Tencent |
| 指标 | TA-Lib + pandas-ta (130+) |
| 知识库 | YAML + Markdown + ChromaDB |
| 回测 | 自研事件驱动引擎 (T+1/涨跌停) |
| 前端 | Streamlit + FastAPI + Plotly |

**P7. 开发流程**
1. 数据层搭建 → 多源数据路由 + PIT处理 + 缓存
2. 分析引擎构建 → 130+指标 + 6市场体制 + 全市场扫描
3. 回测引擎开发 → 事件驱动 + 6层过拟合守卫
4. Agent层开发 → LangGraph工作流 + 7子Agent
5. 知识库构建 → YAML规则 + MD文档 + ChromaDB向量库
6. 前端展示 → Streamlit 7-Tab Dashboard + FastAPI

**P8. 知识库构建过程**
- 三层知识体系: 结构化规则(YAML) + 参考文档(MD) + 向量检索(ChromaDB)
- 知识注入机制: 模板占位符自动替换
- RAG检索: ChromaDB语义搜索 + 关键词fallback
- 提示词版本管理: YAML frontmatter + CHANGELOG

**P9. 提示词工程体系**
- 8个系统级提示词 (每个Agent独立角色定义)
- 4个任务级提示词 (场景化指令)
- 4组Few-shot样例 (带正误标注)
- 评估框架: 4维度评分 (格式/准确性/逻辑/风险)

**P10. 模型路由设计**
- 3层漏斗: Local(免费60%) → Flash(低价30%) → Pro(深度10%)
- 高峰降级: 交易时段自动降级
- 预算控制: 日预算 ¥1,月预算 ¥15
- Fallback链: Pro→Flash→Local 自动降级

**P11. 风控体系**
- 8层风控: 回撤熔断/ATR止损/移动止盈/仓位限制/踩踏防护/持仓天数/跌停检测/相关性监控
- 6级信号评分: STRONG_BUY→STRONG_SELL

**P12. 回测验证**
- 事件驱动引擎: T+1/涨跌停/停牌/手续费全模拟
- 9种策略注册表: 趋势跟踪/均值回归/动量/打板/多因子/资金跟随
- 6层过拟合守卫: PBO/DSR/Walk-Forward/参数敏感度/蒙特卡洛

**P13. 开发工具与流程**
- Git版本管理 + CI/CD (GitHub Actions)
- Docker Compose一键部署
- pytest 50+测试用例 + 竞赛质量评估套件

### 第三部分: 智能体创意创新和价值度 (20分, ~4页)

**P14. 核心创新**
1. **对抗辩论机制**: 行业首创 Bull/Bear/Judge 三方AI辩论,基于同一份量化数据展开论证
2. **代码即推理**: 从根本上杜绝LLM数值幻觉 — 所有数字由代码计算并锁定
3. **3层成本优化路由**: 智能分配任务到本地/低价/深度模型,日均成本<¥1
4. **全真A股模拟**: T+1/涨跌停/手续费/印花税全部模拟,回测结果真实可信

**P15. 实用价值**
- 个人投资者: 降低分析门槛,每天5分钟获取专业级量化报告
- 量化研究员: 提供策略回测验证平台,加速因子研究
- 投资顾问: 快速生成个股/行业分析报告

**P16. 可扩展性**
- 策略插件化: 新增策略只需注册到registry.yaml
- 数据源可扩展: DataSource抽象基类,新增数据源只需实现接口
- Agent可扩展: 子Agent标准接口,支持新增专业Agent
- 提示词热更新: 修改txt文件即时生效,无需重启

**P17. 比赛适应性**
- 完全对标比赛4模块: 架构/知识库/提示词/应用测试
- 90分钟演示剧本已准备
- 自评得分预估: 88/80 (复赛)
