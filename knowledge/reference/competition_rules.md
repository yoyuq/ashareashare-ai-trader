## 三、模拟交易约束 (如适用)

### 交易规则
- T+1 制度: 当日买入,次交易日方可卖出
- 涨跌停限制: 主板±10%, 创业板/科创板±20%, 北交所±30%, ST股±5%
- 最小交易单位: 100股 (1手)
- 交易费用: 佣金0.03% (最低5元), 印花税0.05% (仅卖出), 过户费0.001% (仅沪市)

### 风控约束
- 单票仓位上限: 25%
- 行业集中度上限: 35%
- 日最大回撤: 8%减仓50%, 15%清仓
- 最大持仓天数: 20交易日

### 选股约束
- 排除ST/*ST股票
- 排除上市不满60天的次新股
- 排除日均成交额 < 2000万的僵尸股

## 四、演示要求

### 90分钟演示流程
1. **0-15分钟**: 架构展示 — 智能体设计思路与构架
2. **15-35分钟**: 知识库展示 — 三层知识体系 + 向量检索
3. **35-65分钟**: 智能体搭建展示 — 提示词工程 + LLM配置 + 工作流编排
4. **65-85分钟**: 应用测试展示 — 回答预设问题 + 评委提问
5. **85-90分钟**: 总结与展望

### PPT要求
- 模板结构: 设计思路→开发过程→创意创新→价值度
- 重点突出: 技术亮点 + 创新点 + 实用价值
- 图表要求: Mermaid架构图、工作流拓扑图、评分雷达图
