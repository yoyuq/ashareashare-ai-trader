# A股牛熊周期简史

## 历史重大周期

### 1. 2005-2007 超级牛市 (涨幅: +513%)
- 触发: 股权分置改革 + 人民币升值 + 经济高速增长
- 特征: 全民炒股,成交量持续放大
- 终结: 2008年全球金融危机

### 2. 2008 金融危机熊市 (跌幅: -73%)
- 触发: 次贷危机全球蔓延
- 特征: 恐慌性抛售,千股跌停

### 3. 2014-2015 杠杆牛 (涨幅: +150%)
- 触发: 降息降准 + 融资融券放开 + 一带一路
- 特征: 杠杆资金驱动,创业板暴涨
- 终结: 2015年股灾(去杠杆+熔断)

### 4. 2015-2016 股灾 (跌幅: -49%)
- 触发: 清理场外配资 + 熔断机制
- 特征: 千股跌停,流动性枯竭

### 5. 2019-2021 结构牛 (涨幅: +50-200%,因板块而异)
- 触发: 科创板上线 + 注册制改革 + 核心资产行情
- 特征: 抱团行情(消费/医药/新能源),内部分化严重

### 6. 2022-2023 震荡调整 (跌幅: -20-30%)
- 触发: 疫情反复 + 房地产危机 + 中美博弈
- 特征: 低估值占优,高股息策略逆势上涨

### 7. 2024-2025 科技牛 + 震荡 (持续中)
- 触发: AI产业革命 + 新质生产力政策 + 美联储降息周期
- 特征: 科技股领涨,传统行业分化

## 周期规律总结

1. A股牛短熊长: 牛市平均1-2年,熊市/震荡2-3年
2. 政策驱动强: 货币政策/产业政策对A股影响极大
3. 情绪波动大: 散户占比高,追涨杀跌现象严重
4. 春季躁动: 每年Q1(尤其2-3月)存在季节性行情
5. 五穷六绝七翻身: 5-6月通常弱势,7月有望反弹
6. 年底排名行情: 11-12月机构做账,可能出现异动
