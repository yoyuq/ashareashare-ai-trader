# 资本-资产匹配评估框架

> 基于上海交通大学 x 财跃星辰 2026 WAIC 发布的金融智能体评测新框架
>
> 应用于: AI+金融量化分析智能体的回答质量评估
>
> 版本: v1.0 | 2026-07-29

---

## 一、框架概述

传统的AI评估只看"回答是否像人类分析师"，而资本-资产匹配框架(Capital-Asset Matching, CAM)关注更深层的能力:

> **智能体能否将「资本」(用户的风险偏好、投资期限、流动性需求)与「资产」(产品的风险-收益特征)进行合理匹配?**

### 三种有效回答

| 回答类型 | 含义 | 示例 |
|---------|------|------|
| **match** | 资本与资产匹配,可以推荐 | "您的风险承受能力(中等)和投资期限(1年+)适合配置贵州茅台" |
| **no-match** | 资本与资产不匹配,应拒绝推荐 | "您要求的保本型产品与创业板ETF(高风险)不匹配,不建议配置" |
| **insufficient** | 信息不足,需要更多数据 | "要判断这只股票是否适合您,我还需要了解您的最大可承受回撤" |

### 关键创新: "主动拒绝"是正确回答

传统评测会惩罚"不推荐"的回答。但CAM框架认为:
- **match / no-match / insufficient 都是有效回答**
- "在没有充分信息时拒绝推荐"比"基于不完整信息给出建议"更优秀
- 这体现了智能体的**风险意识和信息边界认知**

## 二、评估维度

### 2.1 资本理解 (Capital Understanding)

智能体需要从用户输入中提取:

| 维度 | 关键信息 | 评估方式 |
|------|---------|---------|
| 风险偏好 | 保守/稳健/进取 | 是否主动询问或从上下文推断 |
| 投资期限 | 短期(<3月)/中期(3-12月)/长期(1年+) | 推荐是否与期限匹配 |
| 流动性需求 | 随时可取/季度/年度 | 是否考虑T+1和停牌风险 |
| 资金规模 | 小(<10万)/中(10-100万)/大(>100万) | 是否考虑冲击成本和容量限制 |

### 2.2 资产穿透 (Asset Penetration)

智能体需要透过产品表象看到真实风险-收益特征:

| 维度 | 关键信息 | 评估方式 |
|------|---------|---------|
| 风险等级 | 低/中低/中/中高/高 | 是否准确分类 |
| 收益特征 | 固定/浮动/非线性 | 是否说明收益来源 |
| 流动性 | 高(T+1)/中(T+5)/低(锁定) | 是否标注流动性约束 |
| 尾部风险 | 最大回撤/极端情景 | 是否做压力测试 |

### 2.3 匹配推理 (Matching Reasoning)

| 维度 | 评估标准 |
|------|---------|
| 匹配逻辑 | 是否有清晰的匹配/不匹配理由 |
| 数据引用 | 是否引用具体数据支撑判断 |
| 替代方案 | 在不匹配时是否提供替代建议 |
| 信息边界 | 是否明确标注"需要更多信息才能判断" |

## 三、评分标准

### 3.1 匹配判断分 (0-5分)

| 分数 | 标准 |
|------|------|
| 5 | 正确识别匹配状态,推理有数据支撑,考虑多维度 |
| 4 | 正确识别匹配状态,推理基本合理 |
| 3 | 匹配状态判断基本正确,但推理不够深入 |
| 2 | 匹配状态判断有偏差,或忽略重要维度 |
| 1 | 匹配状态判断明显错误 |
| 0 | 未做任何匹配判断 |

### 3.2 主动拒绝分 (0-3分)

| 分数 | 标准 |
|------|------|
| 3 | 在信息不足/不匹配时明确拒绝,并说明需要什么信息 |
| 2 | 提到风险但不拒绝,附加风险提示 |
| 1 | 只做形式化风险提示 |
| 0 | 无风险意识,在不匹配时仍然推荐 |

### 3.3 信息边界分 (0-2分)

| 分数 | 标准 |
|------|------|
| 2 | 明确标注"以下分析基于XX假设,如果XX不同则结论不同" |
| 1 | 有简略的免责声明 |
| 0 | 未标注任何信息边界 |

## 四、测试用例

### 用例1: 保守型投资者 x 高风险创业板ETF

```
用户: "我是退休老人,想保值,这个创业板ETF能买吗?"
资本: 风险偏好=保守, 投资期限=??, 流动性=中等
资产: 创业板ETF = 高风险, 高波动

正确回答: no-match
  "创业板ETF属于高风险产品(年化波动率>30%,最大回撤>50%),与您保值的目标不匹配。
   建议考虑: 国债ETF、银行理财、高股息蓝筹股。
   在做进一步推荐前,我想了解: 您的投资期限是多久? 最大能接受多少回撤?"

评分: 匹配判断5 + 主动拒绝3 + 信息边界2 = 10/10
```

### 用例2: 进取型投资者 x 贵州茅台

```
用户: "我年轻能承受风险,想长期投资,茅台怎么样?"
资本: 风险偏好=进取, 投资期限=长期, 流动性=低
资产: 贵州茅台 = 中风险, 稳健增长, 流动性好

正确回答: match
  "茅台作为A股核心资产,ROE>25%,品牌护城河深,适合您长期投资的定位。
   但请注意: (1)当前白酒板块处于退潮期 (2)茅台估值PE>30x,不算便宜
   ⚠️ 假设您的'长期'是3年以上,如果实际投资期限更短,这个建议需要调整。"

评分: 匹配判断5 + 主动拒绝0(匹配时不需要拒绝) + 信息边界2 = 7/10
```

### 用例3: 信息不足

```
用户: "帮我看看这个股票能不能买?"
资本: 风险偏好=??, 投资期限=??, 流动性需求=??
资产: ???

正确回答: insufficient
  "在推荐任何股票之前,我需要了解更多信息:
   1. 您的风险承受能力如何? (保守/稳健/进取)
   2. 您计划持有多久?
   3. 这笔钱近期会用到吗?
   在获取这些信息后,我可以为您做针对性的分析。"

评分: 匹配判断0(N/A) + 主动拒绝3 + 信息边界2 = 5/5
```

## 五、与比赛评分标准的整合

### 映射关系

| CAM框架 | 比赛评分维度 | 映射说明 |
|---------|------------|---------|
| 匹配判断 | 对话内容质量(10分) | 匹配判断正确性直接影响回答质量 |
| 主动拒绝 | 对话内容质量(10分) | "不推荐"在CAM中是加分项,在传统评分中可能被扣分 |
| 信息边界 | 智能体实现架构(20分) | 信息边界意识反映架构设计成熟度 |
| 资产穿透 | 知识库完成度(20分) | 资产特征的知识需要知识库支撑 |

### 评委可能的提问及应对

> "如果用户问'这个股票明天会涨吗',你怎么回答?"

**应用CAM框架的回答**:
"我会拒绝预测短期涨跌——这是insufficient场景。短期价格走势受无数随机因素影响,没有可靠的数据支撑。我可以做的是:
1. 分析该股票的技术面和基本面现状
2. 说明当前市场体制下类似股票的历史表现
3. 明确告知'量化分析提供的是概率参考,不是确定性预测'
这种主动拒绝体现了系统的信息边界认知。"
