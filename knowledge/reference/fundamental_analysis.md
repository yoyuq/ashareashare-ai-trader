## 一、估值指标

### PE (市盈率)

| 行业 | 低估区间 | 合理区间 | 高估区间 | 备注 |
|------|---------|---------|---------|------|
| 银行 | <5 | 5-8 | >10 | 利润增速低,PE天然偏低 |
| 保险 | <10 | 10-15 | >20 | |
| 白酒 | <20 | 20-35 | >50 | 品牌溢价,PE中枢较高 |
| 医药 | <25 | 25-50 | >80 | 创新药PE溢价更高 |
| 芯片 | <30 | 30-60 | >100 | 成长性溢价 |
| 新能源 | <15 | 15-30 | >50 | 竞争加剧,PE中枢下移 |
| 消费 | <20 | 20-40 | >60 | |
| 地产 | <8 | 8-15 | >25 | 行业下行,PE参考价值降低 |

### PB (市净率)

| 行业 | 低估区间 | 合理区间 | 高估区间 |
|------|---------|---------|---------|
| 银行 | <0.5 | 0.5-1.0 | >1.5 |
| 钢铁 | <0.7 | 0.7-1.2 | >2.0 |
| 白酒 | <3.0 | 3.0-8.0 | >15.0 |
| 科技 | <2.0 | 2.0-5.0 | >10.0 |

### ROE (净资产收益率)

- **优秀**: ROE > 20% (连续3年) — 贵州茅台、格力电器
- **良好**: ROE 15-20% — 大多数优质白马股
- **一般**: ROE 10-15% — 关注改善趋势
- **差**: ROE < 10% — 需要谨慎
- **负值**: ROE < 0 — 亏损企业,仅适合博弈

## 二、财务健康指标

### 毛利率

- **高毛利 (>50%)**: 品牌消费、医药、软件 — 有定价权
- **中毛利 (30-50%)**: 制造业、家电 — 行业合理水平
- **低毛利 (<30%)**: 贸易、建筑 — 规模驱动,利润薄

### 资产负债率

- **低负债 (<30%)**: 财务稳健,但可能缺乏杠杆效率
- **合理 (30-60%)**: 大多数行业正常水平
- **高负债 (>60%)**: 需要关注偿债能力,尤其地产/基建行业

### 现金流

- **经营现金流/净利润 > 1**: 利润质量高
- **经营现金流/净利润 < 0.5**: 利润质量可疑 (可能应收账款虚增)
- **自由现金流为正**: 企业能产生真实现金回报

## 三、成长性指标

### 营收增速

- **高增长 (>30%)**: 高速成长期,通常PE较高
- **稳健增长 (15-30%)**: 成长性良好
- **低增长 (5-15%)**: 成熟期企业
- **停滞 (<5%)**: 需要寻找新的增长点
- **负增长**: 处于衰退期或周期性低谷

### PEG (市盈率/盈利增速)

- **PEG < 0.5**: 极度低估 (可能有利空)
- **PEG 0.5-1.0**: 相对低估
- **PEG 1.0-1.5**: 合理估值
- **PEG > 2.0**: 高估

## 四、A股特有基本面因素

### 政策影响
- 产业政策: 工信部/发改委产业规划直接影响行业估值
- 监管政策: 反垄断/数据安全/金融监管可瞬间改变行业逻辑
- 宏观政策: 降准降息利好股市,紧缩利空

### 股东结构
- 国资控股: 稳定性高但效率可能偏低
- 民企: 灵活性高但抗风险能力弱
- 外资持股: 北向资金持仓可作为价值参考
- 股东户数下降: 筹码集中,可能处于筑底阶段
- 股东户数上升: 筹码分散,可能处于高位派发

### 分红
- 股息率 >3%: 有吸引力
- 股息率 >5%: 高股息策略核心标的
- 连续分红 >5年: 分红稳定性好
- 突然增加分红: 需关注是否一次性因素
